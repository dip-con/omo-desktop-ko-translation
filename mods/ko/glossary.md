# 한글 용어집

화면 문구를 번역할 때 같은 영어 용어는 항상 아래 한국어를 씁니다. 사전 검사가 단일 용어 행을 검사합니다.

| 영어 | 한국어 |
|---|---|
| agent | 에이전트 |
| session | 세션 |
| model | 모델 |
| profile | 프로필 |
| memory | 메모리 |
| tool | 도구 |
| workspace | 작업 공간 |
| thread | 대화 |
| project | 프로젝트 |
| provider | 공급자 |
| environment | 환경 |
| server | 서버 |
| settings | 설정 |
| keybinding | 단축키 |
| theme | 테마 |
| branch | 브랜치 |
| checkout | 체크아웃 |
| commit | 커밋 |
| comment | 댓글 |
| browser | 브라우저 |
| prompt | 프롬프트 |
| composer | 입력창 |
| sidebar | 사이드바 |
| terminal | 터미널 |
| snapshot | 스냅샷 |
| extension | 확장 프로그램 |
| pull request | 풀 리퀘스트 |
| storage | 저장 공간 |
| repository | 저장소 |
| diff | diff |

## 풀 리퀘스트와 푸시·풀

| 영어 | 한국어 |
|---|---|
| PR | PR |
| push | 푸시 |
| pull | 풀 |

## 그대로 두는 것

제품명(OmO, Claude, GPT, Git 등), 단축키 이름(Enter, Esc 등), 명령어와 CLI 옵션, 아이콘 이름, 색상 이름 중 번역하지 않는 것은 `keep-english.json`에 이유 분류와 함께 적습니다.
